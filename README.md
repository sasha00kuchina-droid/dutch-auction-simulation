# Голландский аукцион

Учебная симуляция голландского аукциона: генерируется история рыночных цен, агенты с разными стратегиями решают, когда покупать лоты, затем купленные товары распродаются в течение 30 дней. В конце программа считает прибыль и ошибки оценки справедливой цены, строит графики и сохраняет результаты.

## Как запустить в VS Code

1. Скачай и распакуй папку проекта.
2. Открой в VS Code именно папку `auction_project` через **File → Open Folder**.
3. Установи расширение **Python** от Microsoft, если оно ещё не установлено.
4. Открой терминал VS Code: **Terminal → New Terminal**.
5. Создай виртуальное окружение:

   **macOS / Linux:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

   **Windows:**
   ```powershell
   py -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

6. Установи библиотеки:
   ```bash
   python -m pip install -r requirements.txt
   ```
7. Запусти программу:
   ```bash
   python main.py
   ```

Если команда `python` не работает на macOS, попробуй `python3 main.py`.

## Что находится в проекте

- `main.py` — весь код симуляции: модель рынка, лоты, оценщики, стратегии, агенты, аукцион, распродажа, графики и сохранение данных.
- `requirements.txt` — необходимые библиотеки Python.
- `auction_output/` — создаётся автоматически при запуске и содержит результаты.

## Результаты

В `auction_output/` программа сохраняет:

- `agents_summary.csv` — прибыль, выручка и ошибка оценки по агентам;
- `estimation_errors.csv` — ошибки оценки справедливой цены для каждого агента и лота;
- `sold_lots.csv` — информация о купленных и распроданных лотах;
- `auction_results.csv` — победители, цена покупки и шаг аукциона;
- `results.json` — общий отчёт с подробными результатами;
- `agent_profits.png` — прибыль агентов;
- `sale_prices.png` — цены по дням распродажи каждого проданного лота;
- `lot_dynamics.png` — история, снижение цены на аукционе и 30 дней после покупки для выбранного лота;
- `fair_prices_by_lot.png` — история рыночной цены каждого лота с линией его истинной справедливой цены.

## Повторяемость результатов

В начале главного запуска используется `SEED = 42`. При одинаковом seed и неизменном коде случайные последовательности воспроизводятся, поэтому эксперимент можно повторить. Чтобы получить другой сценарий, поменяй значение `SEED` в `main.py`.

## Настройки симуляции

В верхней части `main.py` можно менять параметры товаров, количество лотов, бюджеты агентов и seed. Основная функция `run_simulation()` выполняет весь эксперимент целиком.
